AlanVenture — Portfolio of Alan Xaviour
=======================================
Open index.html in any modern browser (Chrome, Edge, Firefox, Safari). No install or build step.

Pages: index (home) · about · education · skills · projects · certifications · contact
Folders: css/style.css · js/main.js · assets/ (alan.jpg photo, logo.svg favicon)

Tips
- The loading animation + intro screen play once per browser session. Use "Replay intro" in the footer to see them again.
- To change content, edit the text directly in the .html files.
- To publish: upload the whole folder to Netlify / GitHub Pages / any static host.
- Contact form opens the visitor's email app (mailto). For a real form backend, connect Formspree/Netlify Forms.
- LinkedIn link: https://www.linkedin.com/in/alan-xaviour  (edit in index.html and contact.html if your URL differs)
