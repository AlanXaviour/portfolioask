Alan Xaviour — Modern Developer Portfolio
==================================================
Open index.html in any modern web browser (Chrome, Edge, Firefox, Safari).
No installation, node_modules, or build step required.

Highlights & Features:
- Ultra-fast Single Page Application (SPA) architecture with smooth scrolling
- Responsive Dark / Light mode toggle (with localStorage memory)
- High-impact Hero with live typewriter roles and portrait showcase
- One-click CV/Resume view and download (assets/Alan_Xaviour_CV.pdf)
- Complete technical stack breakdown (PHP, MySQL, Java, Python, C++, Cybersecurity)
- Detailed project showcases: AGROW & Location-Based E-Commerce Nursery Platform
- Academic timeline: MCA (Pursuing, Santhigiri College) & BCA (Yuvakshetra)
- Interactive contact form, click-to-call, and one-click clipboard copying for email

Files & Folders:
- index.html: Main portfolio entry point
- css/style.css: Modern glassmorphism & responsive stylesheet
- js/main.js: Particle canvas, typing effect, counters, modal, and theme engine
- assets/: Professional portrait (alan.jpg), PDF resume (Alan_Xaviour_CV.pdf), logo
- _legacy_adventure_theme/: Preserved backup of original multi-page files

To Publish Online:
- Upload this entire folder directly to Netlify, Vercel, GitHub Pages, or any web host.
